# فایل‌هایی که از شما می‌خواهم

هیچ‌کدام از این‌ها اجباری نیست. اپ الان بدون همه‌شان کار می‌کند و این تصمیم عمدی است —
هر پوشه یک قابلیت را **روشن‌تر** می‌کند، نه اینکه چیزی را از کارافتاده نگه دارد.

---

## کجا بگذارم؟

**همهٔ فایل‌ها روی خودِ گوشی، نه در مخزن گیت.**

مسیر، این است و اپ در هر بار اجرا پوشه‌ها را می‌سازد، پس فقط بازشان کنید:

```
Android/data/ir.pixellab.app/files/
├── fonts/        ← قلم‌ها
├── models/       ← مدل هوش مصنوعی
├── luts/         ← جدول‌های رنگ
├── brushes/      ← نوک قلم‌مو
├── hdr/          ← نقشهٔ محیطی سه‌بعدی
├── templates/    ← قالب‌های آماده
├── patterns/     ← الگوها
└── icc/          ← پروفایل رنگ
```

**چرا اینجا:** این پوشه با هر فایل‌منیجری باز می‌شود و **هیچ اجازه‌ای نمی‌خواهد**. نه
دسترسی به حافظه، نه چیز دیگری. فایل را با کابل یا از دانلود کپی می‌کنید و اپ در اجرای
بعدی پیدایش می‌کند.

در خود اپ هم: **تنظیمات ← فایل‌های شما**. مسیر هر پوشه و تعداد فایل‌های پیداشده آنجا
نوشته می‌شود، و دکمهٔ «جست‌وجوی دوباره» بدون بستن اپ دوباره می‌گردد.

**استثنا:** فقط قالب‌ها و الگوهایی که می‌خواهید *همراه اپ منتشر شوند* در مخزن جا دارند.
مدل و HDR هرگز — یکی‌شان از کل برنامه بزرگ‌تر است و مخزن گیت جای فایل صد مگابایتی نیست.

---

## چه فایلی، دقیقاً

### ۱. مدل جداسازی سوژه — بیشترین تأثیر

| | |
|---|---|
| پوشه | `models/` |
| فرمت | `.tflite` |
| پیشنهاد | **U2-Net** یا **MODNet** یا **RMBG-1.4**، کوانتیزه‌شده |
| اندازه | حدود ۱۷۶ مگابایت برای U2-Net کامل، ۵ تا ۲۵ مگابایت برای نسخه‌های سبک |

**بدون آن چه می‌شود:** هیچ. مسیر کلاسیک (برجستگی مرزی + Otsu + مؤلفه‌های همبند) کار
می‌کند و همین حالا فعال است.

**با آن چه بهتر می‌شود:** *تشخیص اینکه سوژه کدام است* — مخصوصاً وقتی سوژه و پس‌زمینه
هم‌رنگ‌اند. **لبه** را در هر دو حالت همان کد پالایش می‌سازد، و لبه است که تصمیم می‌گیرد
مو شبیه مو باشد.

نسخهٔ سبک را ترجیح می‌دهم: تفاوت کیفیتش کم است و ۲۵ مگابایت در برابر ۱۷۶ مگابایت روی
گوشی معنی دارد.

### ۲. مش چهره — برای رتوش

| | |
|---|---|
| پوشه | `models/` |
| فرمت | `.tflite` |
| پیشنهاد | **MediaPipe Face Mesh** (۴۶۸ نقطه) یا **Face Landmark Detection** |
| اندازه | حدود ۲ تا ۱۰ مگابایت |

**بدون آن:** رتوش دستی است — کاربر خودش ناحیه را انتخاب می‌کند.
**با آن:** لاغر کردن صورت، بزرگ کردن چشم، اصلاح لبخند به‌صورت خودکار روی نقاط چهره.

### ۳. جدول‌های رنگ (LUT)

| | |
|---|---|
| پوشه | `luts/` |
| فرمت | `.cube` (متنی، استاندارد Adobe) یا نوار PNG ۵۱۲×۵۱۲ |

هر پکی که برای Premiere، DaVinci یا Lightroom دارید. موتورش ساخته شده و منتظر فایل است.

### ۴. نوک قلم‌موی بافت‌دار

| | |
|---|---|
| پوشه | `brushes/` |
| فرمت | PNG خاکستری، ترجیحاً ۵۱۲×۵۱۲، سفید = رنگ می‌خورد |

**بدون آن:** پنج نوک محاسباتی داریم — گرد، مربع، گچ، پاشیده، موقلم.
**با آن:** بافت *واقعی* — یک قلم‌موی خشک واقعی روی کاغذ، که هیچ فرمولی تقلیدش نمی‌کند.

### ۵. نقشهٔ محیطی برای متن سه‌بعدی

| | |
|---|---|
| پوشه | `hdr/` |
| فرمت | `.hdr` یا `.exr`، تصویر پانوراما (equirectangular) |
| منبع رایگان | Poly Haven — دنبال «studio» یا «softbox» بگردید |

**بدون آن:** استودیوی محاسباتی — سقف روشن، کف تاریک، یک سافت‌باکس. همین حالا کروم را
شبیه کروم می‌کند.
**با آن:** بازتاب چیزهای **قابل‌تشخیص** در فلز، که بیشترِ تفاوت بین حرف رندرشده و حرف
عکاسی‌شده همین است.

### ۶. قالب‌های آماده

| | |
|---|---|
| پوشه | `templates/` |
| فرمت | `.psd` یا `.pxl` (پروژهٔ خود اپ) |

هر جلد یا پستی که به‌عنوان نقطهٔ شروع می‌خواهید. PSD لایه‌به‌لایه خوانده می‌شود.

### ۷. الگوها و پروفایل رنگ

| | |
|---|---|
| `patterns/` | PNG یا JPG — الگوهای بی‌درز ساخته‌شده هست، این‌ها اضافه می‌شوند |
| `icc/` | `.icc` یا `.icm` — برای CMYK و پیش‌نمایش چاپ |

---

## اولویت، اگر فقط یکی را می‌فرستید

1. **مدل جداسازی سبک** (۵–۲۵ مگابایت) — بیشترین تفاوت را در کار روزمره می‌سازد
2. **نقشهٔ HDR استودیویی** — مستقیم به هدف اصلی شما، متن سه‌بعدی، می‌خورد
3. **LUT** — ارزان‌ترین راه برای اینکه خروجی‌ها شبیه هم نباشند

---

## چیزی که نمی‌سازم و دلیلش

**Generative Fill و Expand و Style Transfer.** تنها راهشان یا ابر است — که قید آفلاین
شما را می‌شکند — یا SDXL Turbo با ۱٫۸ گیگابایت، که با سقف ۴۰۰ مگابایتی حافظه و «حجم کم
اپ» جور درنمی‌آید و روی گوشی متوسط اصلاً اجرا نمی‌شود. اگر نظرتان عوض شد بگویید.
