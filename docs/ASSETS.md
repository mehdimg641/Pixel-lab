# فایل‌هایی که از شما می‌خواهم

گفتید مدل سبک نه، فقط سنگین و حرفه‌ای — و گفتید هیچ‌کدام را ندارید. گشتم، مقایسه کردم،
و **هر لینک پایین را با درخواست واقعی HTTP امتحان کردم**. اندازه‌ها از خود سرور خوانده
شده‌اند، نه از حافظه.

هیچ‌کدام اجباری نیست. اپ الان بدون همه‌شان کار می‌کند.

---

## کجا بگذارم؟

**روی خود گوشی، نه در گیت.** اپ در هر اجرا این پوشه‌ها را می‌سازد:

```
Android/data/ir.pixellab.app/files/
├── fonts/        ├── brushes/      ├── patterns/
├── models/       ├── hdr/          └── icc/
├── luts/         ├── templates/
```

این مسیر با هر فایل‌منیجری باز می‌شود و **هیچ اجازه‌ای نمی‌خواهد**. در اپ: **تنظیمات ←
فایل‌های شما** — مسیر هر پوشه، تعداد فایل‌ها، و دکمهٔ «جست‌وجوی دوباره».

---

## ۱. جداسازی سوژه — انتخاب من: BiRefNet

سه مدل امروز در صدرند: **BiRefNet**، **RMBG-2.0** و **BEN2**. مقایسه‌شان روی کاغذ
نزدیک است، ولی برای *این* پروژه یکی‌شان به‌روشنی برنده است.

### ✅ توصیهٔ اول — BiRefNet fp16

```
https://huggingface.co/onnx-community/BiRefNet-ONNX/resolve/main/onnx/model_fp16.onnx
```

| | |
|---|---|
| اندازه | **۴۶۷ مگابایت** (۴۸۹٬۶۶۶٬۲۷۲ بایت — از سرور خوانده شد) |
| مجوز | **MIT** — استفادهٔ تجاری آزاد |
| ورودی | ۱۰۲۴×۱۰۲۴ |
| دانلود | بدون حساب کاربری، مستقیم در مرورگر گوشی |

نسخهٔ کامل fp32 هم هست (**۹۲۸ مگابایت**) ولی روی گوشی دلیلی ندارد: fp16 روی
Snapdragon 8+ Gen 1 دقت عملاً یکسانی دارد و نصف حافظه می‌خواهد.

```
# fp32، اگر واقعاً خواستید
https://huggingface.co/onnx-community/BiRefNet-ONNX/resolve/main/onnx/model.onnx
```

### ⚠️ چرا RMBG-2.0 را توصیه نمی‌کنم

روی بنچمارک‌ها از BiRefNet جلوتر است (۹۰٪ در برابر ۸۵٪) و برای پس‌زمینه‌های شلوغ
واقعاً بهتر است. ولی دو مشکل دارد که برای شما تعیین‌کننده‌اند:

1. **مجوزش غیرتجاری است.** اپ شما متن‌باز است و ممکن است منتشرش کنید.
2. **مخزنش بسته است.** لینکش را امتحان کردم: **HTTP 401**. باید حساب Hugging Face
   بسازید و شرایط را بپذیرید. دانلود مستقیم روی گوشی کار نمی‌کند.

اگر با هر دو مشکل کنار می‌آیید، `briaai/RMBG-2.0` را در Hugging Face باز کنید، شرایط را
بپذیرید و `onnx/model_int8.onnx` (۳۴۹ مگابایت) را بگیرید. اپ می‌خواندش.

### 🎯 اگر بیشتر کارتان پرتره است

```
https://huggingface.co/onnx-community/BiRefNet-portrait-ONNX/resolve/main/onnx/model_fp16.onnx
```
همان ۴۶۷ مگابایت، روی چهره و مو آموزش دیده. برای جلد با سوژهٔ انسانی از نسخهٔ عمومی
بهتر است.

### چه چیزی عوض می‌شود

*تشخیص اینکه سوژه کدام است* — مخصوصاً وقتی سوژه و پس‌زمینه هم‌رنگ‌اند. **لبه** را در هر
دو حالت همان کد پالایش می‌سازد، و لبه است که تصمیم می‌گیرد مو شبیه مو باشد.

### یک واقعیت که باید بگویم

۴۶۷ مگابایت حافظهٔ **native** است، نه heap جاوا — پس بیرون از سقف ۴۰۰ مگابایتی راستر
است و فقط به RAM دستگاه بند است. GT3 شما ۸ تا ۱۶ گیگابایت دارد، پس مشکلی نیست. روی
گوشی ضعیف‌تر تخصیص شکست می‌خورد و اپ **به مسیر کلاسیک برمی‌گردد** — نه اینکه کرش کند.
هر بار هم بعد از استفاده بسته می‌شود: نگه‌داشتن نیم گیگابایت بین دو برش یعنی اپ اولین
چیزی است که سیستم می‌کشد.

## ۲. مش چهره — MediaPipe Face Landmarker

```
https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
```

| | |
|---|---|
| اندازه | **۳٫۶ مگابایت** |
| مجوز | Apache 2.0 |
| نقاط | ۴۷۸ نقطهٔ چهره + blendshape |

اینجا «سنگین» معنی ندارد و مدل بزرگ‌تری وجود ندارد که بهتر باشد: این استاندارد صنعت
است و همان چیزی است که خود گوگل در محصولاتش می‌گذارد.

## ۳. نقشهٔ محیطی برای متن سه‌بعدی — Poly Haven

همه **CC0** (بدون هیچ قیدی) و مستقیماً قابل دانلود:

```
# استودیوی نرم — بهترین شروع برای طلا و کروم
https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/4k/studio_small_09_4k.hdr

# غروب گرم — برای جلدهای گرم
https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/4k/venice_sunset_4k.hdr

# سالن روشن — بازتاب‌های تمیز و خنثی
https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/4k/brown_photostudio_02_4k.hdr
```

نسخهٔ ۴k حدود ۲۰ تا ۵۰ مگابایت است. اگر خواستید سبک‌تر باشد `4k` را در آدرس به `2k`
تغییر دهید (حدود ۶ مگابایت).

بقیه: [polyhaven.com/hdris](https://polyhaven.com/hdris) — دنبال دستهٔ «Studio» بگردید.

**بدون آن:** استودیوی محاسباتی — سقف روشن، کف تاریک، یک سافت‌باکس. همین حالا کروم را
شبیه کروم می‌کند.
**با آن:** بازتاب چیزهای **قابل‌تشخیص** در فلز، که بیشترِ تفاوت بین حرف رندرشده و حرف
عکاسی‌شده همین است.

## ۴. جدول رنگ (LUT)

پوشهٔ `luts/`، فرمت `.cube`. هر پکی که برای Premiere، DaVinci یا Lightroom دارید.
منبع رایگان و خوب: [freshluts.com](https://freshluts.com) — هزاران `.cube` رایگان.

## ۵. نوک قلم‌موی بافت‌دار

پوشهٔ `brushes/`، PNG خاکستری ۵۱۲×۵۱۲ (سفید = رنگ می‌خورد). پنج نوک محاسباتی داریم؛
بافت *واقعی* — قلم‌موی خشک روی کاغذ — را هیچ فرمولی تقلید نمی‌کند.

## ۶. قالب و الگو و پروفایل رنگ

`templates/` — PSD یا `.pxl` · `patterns/` — PNG بی‌درز · `icc/` — پروفایل CMYK.

## ترتیب پیشنهادی

1. **BiRefNet fp16** (۴۶۷ مگابایت) — بیشترین تفاوت در کار روزمره

## چیزی که نمی‌سازم و دلیلش

**Generative Fill و Expand و Style Transfer.** تنها راهشان یا ابر است — که قید آفلاین
شما را می‌شکند — یا SDXL Turbo با ۱٫۸ گیگابایت، که با «حجم کم اپ» جور درنمی‌آید و روی
گوشی متوسط اصلاً اجرا نمی‌شود. اگر نظرتان عوض شد بگویید.
