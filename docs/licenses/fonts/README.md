# فونت‌های همراهِ اپ

چهار فونت نمایشیِ لاتین، همه با پروانهٔ **SIL Open Font License 1.1** — که اجازهٔ همراه‌کردن،
تغییر و توزیع مجدد را می‌دهد، حتی در یک اپ متن‌باز، به شرط نگه‌داشتن همین متن پروانه.

| فونت | چرا | فایل پروانه |
|---|---|---|
| **Anton** | چاق و فشرده. نزدیک‌ترین چیز به فونتی که پوسترها و کاورهای تجاری با آن ست می‌شوند. | `OFL-anton.txt` |
| **Archivo Black** | گروتسکِ سیاه، بازتر از Anton. برای وقتی حروف باید نفس بکشند. | `OFL-archivoblack.txt` |
| **Alfa Slab One** | اسلبِ سنگین. سریف‌های مستطیلی که با اکسترودِ عمیق خوب می‌نشیند. | `OFL-alfaslabone.txt` |
| **Bungee** | برای چیدمان عمودی طراحی شده — تابلوهای شهری. | `OFL-bungee.txt` |

## چرا این‌ها و نه چیز دیگر

فونت‌های فارسیِ خودتان هدف اصلی این اپ‌اند و هیچ‌کدام از این‌ها جایشان را نمی‌گیرند. این‌ها برای
**سنجش** هستند: بیشترِ افکت‌های مرجعی که مقایسه می‌کنیم لاتین‌اند و با یک فونت نمایشیِ خیلی چاق ست
شده‌اند، و وزیرمتن — که فونت *متنی* است — لاتینش به‌مراتب سبک‌تر است. با آن، هر مقایسه‌ای بخش بزرگی
از تفاوتش فقط شکل حروف بود، نه موتور رندر.

## آنچه اینجا نیست

هیچ فونتی از هیچ اپ مرجعی برداشته نشده. هر چهارتا از مخزن رسمی Google Fonts آمده‌اند و پروانه‌شان
کنارشان است — که همان تعهدی است که پاورقی خودِ مخزن می‌دهد: ساخته‌شده بدون استفاده از کد، دارایی یا
طراحی رابط هیچ اپ مرجعی.
