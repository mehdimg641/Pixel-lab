# ساختن APK

```
./gradlew :app:android:assembleRelease
```

خروجی در `app/android/build/outputs/apk/release/` می‌نشیند.

## چرا چند فایل، و کدام را نصب کنم

| فایل | برای چه دستگاهی | حجم |
|---|---:|---:|
| `android-arm64-v8a-release.apk` | تقریباً هر گوشی اندرویدی چند سال اخیر | ~۱۶ مگابایت |
| `android-armeabi-v7a-release.apk` | گوشی‌های قدیمی‌تر ۳۲ بیتی | ~۱۳ مگابایت |
| `android-x86_64-release.apk` | شبیه‌ساز روی کامپیوتر | ~۱۹ مگابایت |
| `android-universal-release.apk` | وقتی نمی‌دانید دستگاه چیست | ~۵۲ مگابایت |

**اول arm64 را امتحان کنید.** اگر «برنامه نصب نشد» داد، arm32 را نصب کنید.

## سه تصمیمی که حجم را از ۱۷۹ به ۱۶ مگابایت آورد

**۱. جدا کردن به‌ازای معماری.** MediaPipe و ONNX هر دو کتابخانهٔ بومی برای چهار معماری
دارند و یک APK که هر چهارتا را ببرد، سه‌چهارمش روی هر گوشی بی‌مصرف است.

**۲. امضا و R8 روی نسخهٔ release.** تا پیش از این هیچ `signingConfig`ای نبود، یعنی
`assembleRelease` فایلی می‌ساخت که اندروید نصبش نمی‌کرد — و تنها بیلدِ قابل‌نصب، همان
debug بود که سه برابر حجم دارد. این وارونه است: بیلدی که به کسی می‌دهید باید کوچک و
بهینه باشد. فقط dex از ۶۲ به ۵ مگابایت آمد.

کلید واقعی از پراپرتی‌های Gradle خوانده می‌شود (`pixellab.keystore` و بقیه). اگر نباشند،
کلید debug استفاده می‌شود تا بیلد **قابل نصب برای تست** باشد. این بیلد **قابل انتشار در
گوگل‌پلی نیست** — برای آن به کلیدی نیاز است که فقط خودتان داشته باشید.

**۳. ONNX Runtime دیگر پیش‌فرض نیست.** بیست‌وهشت مگابایت کد بومی که **تا وقتی خودتان یک
مدل `.onnx` نگذارید هیچ کاری نمی‌کند** — و مسیر کلاسیکِ جداسازی سوژه همان کار را از اولین
اجرا انجام می‌دهد. فرستادن یک موتور استنتاجِ بی‌کار برای همه، تا شاید چند نفر بعداً
قابلیتی را روشن کنند، پیش‌فرض غلطی است.

`OnnxSegmentation.bestIn` وقتی موتور نباشد به مسیر کلاسیک برمی‌گردد، پس کسی که مدل نصب
کرده هم اپِ سالم می‌گیرد نه کرش. اگر خواستید با موتور بسازید:

```
./gradlew :app:android:assembleRelease -Ppixellab.onnx=true
```

## مدلی که **هست**

`face_landmarker.task` گوگل — ۳٫۷ مگابایت، پروانهٔ Apache 2.0، داخل خودِ APK. دانلود
نمی‌شود، چون اپی که ادعای آفلاین بودن دارد نمی‌تواند قابلیتی داشته باشد که اولین
استفاده‌اش به شبکه نیاز دارد. جزئیات در `docs/licenses/README.md`.
