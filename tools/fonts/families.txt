# The faces bundled in the APK, one per line.
#
# Format:  <source>  <identifier>
#
#   gf      a Google Fonts family name, resolved against the google/fonts repository
#   gh      owner/repo/path — a file in some other repository, path given exactly
#
# Blank lines and `#` comments are ignored. `tools/fonts/fetch.py` reads this and writes
# `app/android/src/main/assets/fonts/`; nothing in that directory should be added by hand, because a
# binary nobody can reproduce is a binary nobody can correct.
#
# Where a family publishes a variable font, the fetcher takes it: one file carries every weight, the
# OpenType parser already reads `fvar`, and `Typeface.resolve` already prefers it.
