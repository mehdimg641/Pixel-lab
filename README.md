# Pixel Lab

یک ویرایشگر گرافیک بومی اندروید (Kotlin) برای تولید محتوا — با اولویت
**کاور و متن سه‌بعدی فارسی**.

پیاده‌سازی مستقل و متن‌باز. هیچ کد یا دارایی‌ای از اپ‌های مرجع در این پروژه
استفاده نمی‌شود.

## وضعیت

مرحلهٔ طراحی. هنوز کدی نوشته نشده.

📄 **[کاتالوگ فیچرها و تحقیق](docs/FEATURE-RESEARCH.md)** — ادغام قابلیت‌های هشت اپ مرجع،
اولویت‌بندی، و معماری رندر. **سند اصلی و به‌روز.**

📄 **[کالبدشکافی استایل‌ها](docs/STYLE-ANATOMY.md)** — تحلیل لایه‌به‌لایهٔ نمونه‌های مرجع،
مدل دادهٔ استایل، و قابلیت‌های استخراج‌شده.

📄 **[فهرست فونت‌ها](docs/FONT-INVENTORY.md)** — تحلیل ۳۱۲ فونت فارسی، محورهای متغیر،
و الزامات مدیر فونت.

📄 **[نقشهٔ راه اولیه](docs/ROADMAP.md)** — تحلیل متن فارسی، مدل داده، و استراتژی تست.
بخش معماری رندرش با سند بالا جایگزین شده.

## هدف

یک ویرایشگر لایه‌محور که جای چند اپ را بگیرد: عمق افکت‌های متنی PixelLab،
سه‌بعدی واقعی Tenada، قالب‌ها و برند کیت Canva، مدل سند فتوشاپ (ماسک لایه،
حالت‌های ترکیب، لایهٔ تنظیم)، جداسازی سوژهٔ Photoroom، و رتوش AirBrush —
همه آفلاین.

تفاوت اصلی با اپ‌های موجود: **متن فارسی درست رندر می‌شود** — اتصال حروف، جهت
راست‌به‌چپ و کشیده، حتی وقتی متن به هندسهٔ سه‌بعدی تبدیل می‌شود.
