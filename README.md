# Pixel Lab

یک ویرایشگر «متن روی عکس» بومی اندروید (Kotlin) — با پشتیبانی درست از فارسی.

پیاده‌سازی مستقل و متن‌باز، الهام‌گرفته از قابلیت‌های اپ PixelLab. هیچ کد یا
دارایی‌ای از آن اپ در این پروژه استفاده نمی‌شود.

## وضعیت

مرحلهٔ طراحی. هنوز کدی نوشته نشده.

📄 **[بررسی فنی و نقشهٔ راه](docs/ROADMAP.md)** — معماری، پشتهٔ فناوری، فازبندی و ریسک‌ها.

## هدف

ویرایشگر لایه‌محوری که بشود با آن متن، تصویر، شکل و استیکر را روی یک بوم ترکیب کرد،
با افکت‌های متنی کامل (گرادیان، خط دور، سایه، سه‌بعدی، منحنی، پرسپکتیو) و خروجی
با رزولوشن دلخواه.

تفاوت اصلی با اپ اصلی: **متن فارسی درست رندر می‌شود** — اتصال حروف و جهت
راست‌به‌چپ حتی وقتی افکت سه‌بعدی یا متن منحنی فعال است.
